# receipt-app
/**
 * ============================================================
 * レシート管理アプリ - Google Apps Script（APIサーバー）
 * 部署コード認証方式 ／ GitHub Pages 連携版
 * ============================================================
 *
 * 【役割】
 * このスクリプトは画面を表示しません。
 * GitHub Pages に置いた index.html から呼ばれるAPIとして動作します。
 *
 * 【初期設定】
 * 1. 下の CONFIG を設定
 * 2. setupMasterSheet() を1度実行（管理シートの雛形作成）
 * 3. 部署タブに部署名と部署コードを入力
 * 4. createDepartmentSheets() を実行（部署別シートを自動生成）
 * 5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で公開
 *    - 次のユーザーとして実行： 自分
 *    - アクセスできるユーザー： 全員
 * 6. 発行されたURLを index.html の API_URL に設定
 *
 * 【手動実行する関数】
 *   setupMasterSheet()       初回のみ。部署タブを作成する
 *   checkDepartments()       現在の部署設定を確認（変更なし・安全）
 *   createDepartmentSheets() 未作成の部署のシートを生成（何度でも実行可）
 *   resetMasterSheet()       部署タブを強制初期化（★データ紐付けが切れます★）
 *
 * 【仕様変更・再デプロイ時】
 * 部署タブのスプレッドシートIDはそのまま保持されます。
 * コードを貼り替えても既存データへの影響はありません。
 * ただし setupMasterSheet() は再実行しないでください
 * （ガードで停止しますが、resetMasterSheet() は紐付けを失います）。
 *
 * 【重要】
 * 管理用スプレッドシートは誰にも共有しないでください。
 * スクリプトが管理者権限で読むため、利用者への共有は不要です。
 */
